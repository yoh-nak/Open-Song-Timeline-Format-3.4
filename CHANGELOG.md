# Changelog

## 3.4.0 — Official specification

Specification established: 2026-10-31. GitHub publication edition prepared: 2026-11-01.

### Format changes from 3.3

- Native initial key, later key changes, default scale and targeted timed scale contexts.
- Native song languages, primary lyric document, moods and authored rights statements.
- Nominal timeline duration, bar origin and additive beat grouping.
- Document lineage/revisions and typed, non-executable provenance.
- Relative phrases, generation, presentation, phrase library, clip choices and localization as named Core objects.
- Source-template velocity with independent/linked instance semantics.
- Explicit Core authority, shared-metadata merge approval, non-destructive preservation and migration rules.
- Optional extensions retained only for compatibility; frozen legacy definitions retain their old version contracts.

Existing genres, credits, voicing, tempo, meter, notes, percussion and primary melody are reused, not redefined in competing fields.

### Publication-edition changes

The already established Japanese normative specification and all five schemas are preserved byte for byte. This edition does not silently change the Core design. It adds complete bilingual manuals, a complete English specification translation, full references including every structural branch and all frozen definitions, and an all-current-field/enum witness index.

Expanded focused samples from 22 to 54; retained eleven 3.4 demos byte for byte. Organized exactly 100 files with no nested archives. Replaced links to omitted source archives with source inventory/hashes, corrected the license's material-title version label, and updated release tooling/documentation. These packaging/editorial changes do not confer new rights on musical demos.

No device-runtime tests, instrument generation, playback or remote GitHub publishing were performed.

## 3.0–3.3

Historical schemas are included unchanged for original-version reading and explicit migration. Their histories are not retroactively rewritten by this 3.4 document.
